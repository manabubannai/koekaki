# メルマガ用リリース文(NoType v3.1.0)

しゃべるだけでメモが書ける無料Macアプリを大きくアップデートして、名前も「NoType」に変えました(旧名: Koekaki)。キーボードを打たない、という意味です。

今回の目玉は「自動貼り付け」。いままでは録音を止めるとクリップボードにコピーされて、⌘Vを自分で押す必要がありました。新版は録音を止めた瞬間、AIが文字起こしして、カーソル位置にそのまま文字が入ります。superwhisperと同じ体験です。文章を書く流れが一切止まりません(⚙️設定でオフにもできます)。

見た目も一新しました。ウィンドウを無くしてメニューバー常駐型に(録音中はアイコンが赤丸+経過秒に変化)。録音の開始と停止では控えめな効果音が鳴るので、画面を見なくても状態がわかります。設定画面はsuperwhisper風のダーク配色、アイコンも新しくしました。中身は変わらず、AI音声認識(whisper large-v3-turbo)がMacの中だけで動くので、音声はどこにも送信されません。登録なし、広告なし。

使い方: 文字を入れたい場所にカーソルを置いて、ショートカットキー(初期設定 ⌥Space。superwhisperと同じFn単独キーにも変更可)で話しはじめ、もう一度押して終了。それだけです。初回だけ、マイクと「アクセシビリティ」(自動貼り付けに必要)の許可をお願いします。
