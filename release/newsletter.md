# メルマガ用リリース文(Koekaki v2.0.0)

しゃべるだけでメモが書ける無料Macアプリ「Koekaki」を大幅アップデートしました。

今回の目玉は、頭脳の入れ替えです。superwhisperと同系統のAI音声認識（whisper large-v3-turbo）をアプリに丸ごと同梱しました。認識精度が別物になり、句読点まで自動で入ります。AIはMacの中で動くので、音声はどこにも送信されません。そのぶんアプリは約550MBあります。

使い方は変わらずシンプルで、常に最前面の小さな窓のボタンを1クリックで録音開始、もう1クリックで停止すると、AIが文字起こしして全文がクリップボードへ（あとは⌘Vで貼るだけ）。ショートカットキー（初期設定は ⌥Space、変更可）でも録音のオン/オフができます。登録なし、広告なし。

ダウンロード(zip解凍→アプリケーションへ。初回だけマイクを許可。macOS 13以降/Apple Silicon):
