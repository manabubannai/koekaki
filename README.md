# NoType — しゃべるだけでメモが書ける無料Macアプリ

ショートカットキーを押して話すだけで、カーソル位置にそのまま文字が入ります。キーボードを打たない、という意味で NoType です。

AI音声認識（whisper large-v3-turbo）をアプリに同梱していて、Macの中だけで動きます。音声はどこにも送信されません。登録なし、広告なし、無料です。

**ダウンロード**: [最新版 NoType.app（zip）](https://github.com/manabubannai/koekaki/releases/download/v3.1.0/NoType.zip)

macOS 13以降 / Apple Silicon。Apple公証済みなので、解凍してアプリケーションフォルダに入れるだけで開けます。

## 使い方

1. 起動するとメニューバーにアイコンが出ます（録音中は赤丸と経過秒に変わります）
2. 文字を入れたい場所にカーソルを置き、ショートカットキー（初期設定 ⌥Space）で録音開始
3. 話し終わったら、もう一度押して停止
4. AIが文字起こしして、カーソル位置へ自動で貼り付きます（クリップボードにも残ります）

初回だけ、2つの許可が必要です。

- マイク: 初回録音時にダイアログが出ます
- アクセシビリティ: システム設定 → プライバシーとセキュリティ → アクセシビリティ で NoType をオンに（自動貼り付けに必要）

## 設定

⚙️設定から変更できます。

- ショートカットキー（⌥Space のほか、Fn単独キーなどに変更可）
- 自動貼り付けのオン/オフ（オフの場合はクリップボードにコピーのみ。⌘Vで貼り付け）
- 録音の開始音・停止音のオン/オフ

## 不具合の報告

メニューの「バグを報告」からワンクリックでメールできます。

## ビルド

```
./build.sh   # dist/NoType.app ができる
```

Swift / SPM。音声認識は whisper.cpp ベースのローカル推論を同梱しています。
